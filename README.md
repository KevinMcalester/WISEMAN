# WiSeMAN

## Wireless Sensor and Mobile Autonomous Networks

This repository serves as a shared software development and research continuity environment for **WiSeMAN students**.

The repository is centered around the **Ground Control System (GCS)** and the software developed for WiSeMAN's Q systems and sensor systems.

## Ground Control System (GCS)

The GCS directory contains software associated with the WiSeMAN Ground Control System.

The GCS provides the common software environment used to communicate with, monitor, control, and visualize supported WiSeMAN systems.

## QDrones

The QDrones directory contains software developed for WiSeMAN drone systems.

Refer to the WiSeMAN public documentation for information regarding the QDrone system, architecture, operation, and research.

## QCars

The QCars directory contains software developed for WiSeMAN autonomous vehicle systems.

Refer to the WiSeMAN public documentation for information regarding the QCar system, architecture, operation, and research.

## Sensors

The Sensors directory contains software associated with WiSeMAN sensor systems and their integration with the GCS and Q systems.
